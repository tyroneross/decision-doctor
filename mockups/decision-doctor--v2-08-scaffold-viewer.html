# Pre-auth letter skill

When the user asks for a pre-authorization letter, ask for these four
fields if any are missing:
- Diagnosis (ICD-10 if known)
- Procedure / medication being requested
- Clinical justification (one sentence)
- Payer / plan

Then produce a letter ≤ 350 words in this format:
- Header line (date, payer)
- Patient identifier line (placeholders only — no PHI)
- 2-sentence clinical summary
- Requested service line
- Justification paragraph (3-4 sentences)
- Sign-off block

Never include PHI in worked examples. Use placeholders.
