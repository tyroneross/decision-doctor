## Project non-negotiables (`decision-doctor-cc/CLAUDE.md`)

- Railway owns crawler/queue/rendering/enrichment/embeddings/KG. Vercel owns UI + chat/search APIs + light enqueue/read paths.
- Queue stays on **pg-boss**. Do NOT add BullMQ/Redis unless a measured bottleneck proves it is needed.
- Crawler code under `workers/src` only. Worker `tsconfig` is scoped there.
- Do NOT import Interface Built Right as a runtime dependency. CDP on Railway uses apt-prebuilt Chromium; render concurrency = 1.
- Do NOT add Chromium through Nix `nixPkgs`.
- Respect `ai_sources.source_kind` CHECK: only `lab_news | lab_research | paper_index | industry_news | user_url | user_rss | user_file`. Discovery method (`rss | sitemap | api | html | pdf | cdp`) lives in `crawl_config`, not `source_kind`.
- `kg-extract` constrains entity types to DB allow-list: `organization, model, product, person, benchmark, capability, technique, paper, standard, other`.
- Every handler is idempotent. Mark `degraded:true` rather than block the chain.

## Hard-stop conditions

Halt and surface to user (don't iterate-and-continue) when:

- `scripts/check-integration.sh` returns exit 2 (merge-conflict surface with other worktree).
- A commit needs to touch the other side of the file-ownership boundary.
- `pnpm typecheck` regresses from green.
- `pnpm build` route count drops below 15.
- A non-flake test fails 3 consecutive runs.
- Autonomy gate returns `confirm` or `block` for a destructive/unplanned action.
- 5 iterations on the same chunk without convergence.
- 8h wall-clock without a successful Review pass.
